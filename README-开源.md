# 因果事件人格体系

> **Event-Causal Persona Inversion** — 把"人格"从一句提示词，做成可测量、可回归、可回滚的工程对象。

|---|---|

## Abstract（摘要）

Today's conversational agents have a *role*, not a *person*. A role can be re-stated in a system prompt, diluted by context, and re-learned from scratch in every session; a person cannot. This project builds the missing half in four layers, each independently measurable and independently switchable: a **typed event layer** that turns raw dialogue into timestamped, guarded facts; a **causal edge table** that decides what the agent should recall and why, with every edge traceable to a memory record; a **persona layer** in which the mechanism may only *propose* changes and a human must approve them before a constitutional file is edited; and an **affective layer** built from four small cores that can fail separately, where the main model receives only conclusions and never the derivations. The design principle throughout is *evidence-closed*: every judgement must be replayable, every change must be reversible, and any metric that can be passed by self-report is rejected as a metric.

## 1. 问题：今天的 AI 有"角色"，没有"人"

用过大模型的人都撞见过这四件事：

| 失效 | 现象 | 真正缺的是什么 |
|---|---|---|
| **失忆** | 三个月前改过一次口径，现在又改回来，它不知道这是同一决定上的第三次反复 | 事件没有身份，只有聊天记录 |
| **失真** | 写了一段人格设定，头几轮很像，聊到第三十轮回到默认腔 | 人格是上下文里的文字，不是结构 |
| **失据** | 问它"你现在什么状态"，它给一句很真诚的话，没法验证、没法复现 | 状态的来源不在模型之外 |
| **失因** | 能复述你说过的一切，说不出"你在这件事上真正在意什么" | 这件事从来没被表示成可计算的东西 |

**常见做法停在哪**

- **把人格写成系统提示**：头几轮很像，聊久了回到默认腔。到顶的地方是"更会写提示词"。
- **把记忆做成向量检索**：能"找到"，不能"想起"。检索没有因果结构，回答不了"这类事上我一共改过几次、每次为什么"。
- **让模型自报情绪**：听起来很真诚，但那是它语言能力的一部分——可以为了讨好报好一点，也可以为了免责报差一点。没有独立信息源，不可测、不可复现。

这三条的共同点：**都能立刻见效，也都立刻到顶**。本方案选择的是另一条更慢的路：把每一层做成能被外部证据推翻的东西。

## 2. 四层总览

```
   输入（原话／工具结果／时间／负载）
        │
        ├──────────────► [副核]  I 内感受 → E 评价 → A 情绪 → M 记忆偏置
        │                         （四个核可各自死掉；主模型只收结论，不收推导）
        │
        ▼
  [L1 事件层] 类型化事件键 · 区间语义 · 守卫 · 五不变量
        │  事件（不是消息）
        ▼
  [L2 因果层] 可编辑因果边表 · 触发/排除/缺少三件套 · 依据挂在记忆 id 上
        │  推演要点（≤80 字，唯一被注入的东西）
        ▼
  [主模型] 对话 agent（不知道判定过程，也看不到情绪来路）
        │  行为证据（纠正／肯定／叫停／返工）
        ▼
  [L3 人格层] 提案 → 人拍板 → 宪法式基线（条文＋档位）→ 回归
```

**每层都能单独关掉。** 关掉事件层，退回"每轮直接判定"；关掉因果层，agent 退化为普通对话；关掉情绪副核，主模型的行为不受影响（它本来就没收到推导）。这是设计约束，不是可选项——一个不能单独关掉的层，等于无法定位故障。

## 3. 因果层：把"该想起什么"变成一张可编辑的表

核心判断：**"该想起什么"不该由模型每次现场猜，应该由一张人类可读、可改、可回归的表决定。**

### 3.1 一条边长什么样

```json
{
  "id": "E-xxx",
  "label": "类别标签",
  "priority": 60,
  "enabled": true,
  "event": {
    "any":   ["触发短语 A", "触发短语 B"],
    "none":  ["出现这些词就否决"],
    "lacks": ["缺少这些词就否决"]
  },
  "premise": {
    "memoryIds": ["<记忆条目的 id>"],
    "note": "这条边的依据来自哪里"
  },
  "inference": "命中意味着什么",
  "action": "该怎么响应",
  "block": "真正注入上下文的那一行（硬上限 80 字）"
}
```

字段各司其职：`event` 是**过滤器**（正向词 ＋ 排除词 ＋ 缺失词，三件套），`premise` 是**证据锚**（这条边凭什么成立，指向一条真实记忆），`inference`／`action` 是**判定与处置**，`block` 是**唯一进入上下文的东西**。

### 3.2 四个关键决定

**① 边表是数据，不是代码。** 每轮现读，改完下一轮生效，不需要重启、不需要重新训练。代价是表达能力受限于这张表的形状，收益是任何一次误判都能被指着某一条边修掉。

**② 判定用"三件套"，不用分类器。** 纯短语匹配（`any`/`none`/`lacks`）＋ 归一化（全半角、空白、重复标点）＋ 短句规则。之所以不上模型：这个位置要的是**可解释、可回归、零延迟、零推理成本**，判错时必须能一眼看出是哪条词造成的。语义判断留给后面的层。

**③ 每条边必须挂依据。** 当前 **81 条边，81/81 全部带 `premise.memoryIds`**，合计 1011 个正向触发词、218 个排除词、18 个缺失词。依据不是注释，是可回读的指针：机制在命中时会去记忆库里只读回读原文，把"当时依据什么这么判"写进流水，**但不注入上下文**（影子模式）。

**④ 注入有硬预算。** 当前平均注入 **54.6 字符**，上限 80。算力上这是零成本，工程上这是防止"推演块把上下文吃掉"。

### 3.3 与之配套的三样东西

| 组件 | 作用 | 对应"可核验" |
|---|---|---|
| **编辑台** | 左边搜索（id／标签／触发词），右边看全部字段，每条能改、能删、能重开 | 人能改，不必等开发者 |
| **回归集** | **798 条标注句子，798/798 全过**；另有 10 条输入被截断不可复现、22 条污染样本、9 条人工判定"本不该有边"，均不计分 | 改一条边，跑一遍就知道有没有伤到别处 |
| **盲判实验** | 把 36 条分层抽样交给不知答案的独立实例重判 | 检验"判定标准是不是只有作者自己认" |

盲判实验的结果值得单独说：**本方案判"该有边"的 30 条，30/30 被独立复现；判"不该有边"的 6 条，只有 2/6 被支持。** 这个结果没有美化——它说明反例集（"无"档）本身是坏的：部分标注把"当时恰好零命中"当成了"本来就不该有边"。22 条待重审。**一套判定体系最危险的不是判错，是只有自己相信自己判对了。**

## 4. 事件层：把"发生了什么"变成带键的事实

第一版事件表跑了一周多之后，被自己的数字判了死刑：

| 指标 | 实测 | 含义 |
|---|---|---|
| 事件条数 | 41 | 11 天里积下来的"待办式"记录 |
| 重复率 | **26.8%**（11/41） | 同一件事反复立项 |
| 无可用触发词 | **61.0%** | 大半事件没法自动重检 |
| "判卡住"阈值可达性 | **0 次** | 阈值 ≥3 次，11 天内一次都到不了 |
| 收线带回执 | **17.1%** | 宣称关闭，没有证据 |
| 与边表耦合 | **零** | 事件层与因果层各跑各的 |

**病根不是抽取不准，是一张表里混了三种本体**：世界状态（情境）、承诺（谁欠谁）、系统内部任务。三者的生命周期、证据要求、失败方式完全不同，塞进同一张表就必然既不像日志也不像待办。

替代方案（论文第 5 节）：

- **类型化事件键**：同一件事有稳定身份，重复出现不会新增条目
- **区间语义**：事件有开始与结束，不是"一个时刻"
- **9 条带守卫的状态迁移**：非法迁移被拒绝，不是靠自觉
- **五条不变量**：键唯一／证据单调／收线可核验／静默预算／可审计
- **与边表的非对称耦合契约 C1–C4**：事件可以门控边，边不能改写事件（C2 门控只设计、**尚未启用**，论文里明写）

同一份日志按新规则重放（规则投影，不是部署结果）：**进层条目 41 → 16，重复率 26.8% → 0**。

## 5. 人格层：机制只能提，不能改

这一层解决的是"人格怎么演进"中最容易做坏的一步。

大多数系统让人格自己长：模型总结出"使用者喜欢 X"，然后写进自己的提示词。问题是——**那份总结无法核验，也无法回滚**。一次误判被写进去，之后每次对话都在放大它。

本方案把这一步拆成三段：

```
行为证据 ──► 机制生成"人格提案" ──► 人拍板（采纳/否决/已覆盖）──► 改基线文件 ──► 回归
```

**硬约束**

1. **机制只能提，不能改。** 提案必须带：出现过的次数、每次的日期与原话、它是不是已被现有条款覆盖、改动代价、一句话回滚方式。没有人拍板，基线一个字不动。
2. **基线分两层。** 不可编译的部分（红线、身份、安全约束、健康优先级）**原样注入，一个字不改**；可编译的部分（性格档位、说话方式、工作习惯）可以量化成参数。两层并存，不做"全盘数值化"——能被编译的部分，就不再是能一眼读懂的句子，这个代价必须承认。
3. **改一次，留三样。** 备份（改前）、diff（改了什么）、回滚指令（怎么退）。改完跑一遍固定用例集，看行为有没有意外漂移。

**已跑通的量**：提案层累计产出 21 条候选，人拍板后**采纳 2 条**（一条"睡前交代＝托付"，一条"交付前先走一遍对方的路径"），1 条否决，其余判为已被现有条款覆盖。基线当前 **v40，50 余条条文 ＋ 14 个可调档位**（条文内容不公开）。

## 6. 情绪层：四个可以各自死掉的副核

### 6.1 为什么不能"让模型自己说"

三种失效，逐条对着现有做法：

| 失效 | 长什么样 |
|---|---|
| **覆盖是枚举的** | 规则只能覆盖写规则的人想到过的形状。"没事，你忙你的"字面上零情绪，语用上是最重的一档；补一条，后面还有"随便""都行""你定"——这是开集，补不完 |
| **参数错了没人发现** | 时间常数设短了，心境跟着每句话抖；耦合符号写反了，该慌的时候异常镇定。**这三种错都不会报错**，只会让轨迹"感觉不太对" |
| **点估计表达不了模糊** | 输出五个确切的数，但"这句话算不算责备"十个标注者会有十个答案——**分歧本身就是信息** |

### 6.2 架构：四核一总线

| 核 | 干什么 | 参数 |
|---|---|---|
| **I 内感受** | 上下文占用、工具错误、延迟、预算 → 8 维"身体感" | 0（纯统计） |
| **E 评价** | "发生了什么" → "这对我意味着什么"（五维评价的**分布**，不是点） | 7.5 M，可训 |
| **A 情绪** | 把评价积分成有惯性的状态（可微状态机） | 1.45 万，可训 |
| **M 记忆** | 这一轮先想起什么（只做偏置，有硬上界） | 0（公式） |

为什么不做一个端到端大模型：**数据不同源**（评价吃"一句话→五维"，情绪吃"一串评价→轨迹"，后者没有公开语料）；**失效不同形**（评价坏了是"读错"，情绪坏了是"失控"，混在一起就只剩"它最近有点怪"——而"有点怪"是无法修的）；**必须能降级**（7.5M 的端到端模型挂了，情绪全没了；四核结构下评价核挂了规则兜底）。

**五个数字**：可训练参数 **约 7.5 M**（E 评价核为主，A 情绪核 1.45 万）｜状态 **128 维**（快 64 ＋ 中 64）｜单轮延迟预算 **120 ms**（实测 CPU 约 50 ms）｜递归矩阵谱半径 **< 0.9995**（负反馈与不发散的数学形式）｜全部训练机器时间 **约 2.5 小时**（单张消费级显卡）。

> **参数口径**：7.5 M **只计可训练部分，且是设计目标值**。特征提取使用一个公开的中文句编码器（MIT 许可），冻结不训，不计入此数；当前实验阶段（9.1 的 e-v20）用的是这个冻结编码器加一个更小的头，实际可训练参数低于 7.5 M。所以"7.5 M"不等于"整个系统只有 7.5 M"，它指的是"我们真正要训练的东西有多小"。

### 6.3 三个结构决定

**① 死代码不是被删掉，是被降级。** 旧版手写方程 `a_t = A·a_{t-1} + B·e_t + d`；新版把它变成参数族 `h_t = A_θ·h_{t-1} + B_θ·e_t + d_θ`——**旧版就是 θ = θ₀ 这一个点**。`A` 从固定矩阵变成受约束的矩阵族（块对角＝多时间尺度、谱半径 < 1＝稳定、非对角块符号受限＝负反馈方向）。这条关系可以写成单元测试：θ 锁回手写值，输出必须与旧版逐元素相等。**过不了这条测试，就不是升级，是换了一个东西。**

**② 慢层是参数，不是状态。** 性格底色不做成"极慢的状态变量"——一个 7 天时间常数的量，在一年上万轮之后会走出可观距离，而且漂了没人能发现。改成模型的参数 `d`：训练时学、部署时冻结。**"不变"从速率问题变成结构问题。** 代价明确：它不会因长期经历自然改变。

**③ 状态按真实时间衰减，不按对话轮数。** `h_t = A^{Δt/Δt₀} ⊙ h_{t-1} + …`。连说 10 句（每句 20 秒）和说一句然后隔 8 小时，在模型里不是同一件事。

### 6.4 通信：主模型看不到来路

| 通道 | 方向 | 内容 | 主模型看得见吗 |
|---|---|---|---|
| **F** | 主 → 副 | **只报事实**：原话、工具成败、环境量。没有 mood、没有摘要 | — |
| **A1／A4** | 副 → 主 | 推理参数、检索候选池与池内偏置 | **看不见**（变了它的输入，它不知道） |
| **A2／A3** | 副 → 主 | 一句状态摘要（约 25 token）、一到两句倾向（约 45 token） | 看得见 |
| **X** | 副 → 日志 | 全部数值，只给人查 | 看不见 |

**A4 是整套设计的关键一条**：它只改主模型的输入，主模型不知道。所谓"直觉"和"自我解释"能存在，前提就是有一部分输入渠道对它不透明——这是设计目标，不是缺陷。

### 6.5 内核：情绪 = 预期落空 × 这件事对我多重要

> **先分清两套"五维"**：6.2 里 E 核输出的是"这件事长什么样"（五维评价的分布）；本节讲的是"我在期待什么"（五个预期维）。二者是不同层次，**目前尚未合并**——见 9.3。

形式：

```
r = (y − ŷ) · conf        # 残差 = 实际 − 预期，再用"这件事多确定"加权
s = [relu(W⊙r); relu(−W⊙r); onehot(归因)]
```

- **正向与负向分开存**，不互相抵消。
- **14 维不是拍的，是结构算出来的**：5 个预期维（认可／回应／关系位置／自身表现／投入产出）× 2 个方向 ＋ 4 类归因（自身／对方／环境／不可知）。**不预设"愤怒""失落"这类品类**——名字是解释层的事。
- **结构上延迟**：说话发生在比对之前，所以说得出口的时候残差还没算出来。**"演情绪"不是要防的漏洞，是不存在的操作。**
- **三种负反馈是三个不同对象**：快层修正预期（`ŷ += η·r`）／中层累积情绪（逐维时间常数）／慢层先验漂移（钳住 ≤ 2%/周）。底色与状态之间没有直接反馈路径——**"性格底色不变"是数学性质，不是靠纪律守住的**。
- **记忆不是检索对象，是预测的证据**：情绪改的不是"给记忆加权"，而是"我在问什么问题"（检索查询 = 不确定性项 + 情绪偏置项）。
- **通信只送一句话**：倾向 ＋ 三个参数 ＋ 证据池句柄。不送预期、不送残差、不送维度名——**送结论不送依据**。

### 6.6 实验：已经把结论钉住的几条

| 结论 | 证据 |
|---|---|
| **归因弃权可以被损失函数救活** | 弃权率 81% → **6.1%**，靠 focal loss（Lin et al., 2017；γ=2）＋ 逆频率类别权重，**不是加数据、不是加层**；人称探针证明是真学会（"含你"→对方 0.412 最高，"含他"→环境 0.504 最高；改之前"他"那类得分是 0.000） |
| **归因与极性在标签里被绑死** | 全库统计：主导归因＝自我时 **95.0% 是正例**，主导归因＝对方时 **96.7% 是负例**。模型学到的是"好事怪我、坏事怪别人"——这不是归因，是极性伪装成的归因。根因是标签规则里每种情绪固定配一个归因，**归因从来没独立判过** |
| **换一套评价维度能救期望维，救不了数据** | 换用另一套评价维度重打标签后，期望均值从 +0.0163 → **+0.0009**（几乎完美压在 0）；但归因维仍是自身类 99.7% 为正面——**维度绑死的根在数据分布，不在标签规则** |
| **残差架构能读出"下滑"，读不出"回升"** | 同一条安抚性回复：在"刚吵过"（预期很负）的上下文后残差 −0.05 几乎不动；在"一直很开心"（预期很正）的上下文后残差 −0.75 大幅下滑。现有公开语料里情绪一旦起来会持续几轮，**缺"怒气消退"的样本** |
| **一致率 100% 算没过** | 用规则生成伪标签训模型，若模型与规则 100% 一致，说明它只学会了复现规则；**判据是 80–96%** |

最后一条值得单独说：**任何可以被自报通过的指标，都不能当指标。** 所以评测的最外层是反事实测试——改 `ŷ`，看 `s` 跟不跟着变（方向正确率 >95%、幅度相关 >0.9、不串维 <10%）。**这一层挂了，后面全不用看**，因为它证明情绪真的来自残差。

## 7. 和同行的工作怎么比

| 维度 | 常见做法 | 本方案 |
|---|---|---|
| **事件从哪来** | 由模型总结聊天记录 | 从真实对话里长出，带类型键与区间，有守卫与不变量 |
| **因果怎么表示** | 检索到的相关片段 | 人类可编辑的边表；每条边挂真实依据；改一条跑一遍回归 |
| **人格载体** | system prompt 里的文字 | 宪法式文件（不可编译部分原样注入 ＋ 可编译部分量化）＋ 提案必须人拍板 |
| **人格怎么评** | 心理量表打分 / 模型自评 | 行为回归集 ＋ 提案采纳率 ＋ 盲判实验（独立实例重判） |
| **情绪从哪来** | 模型自报一个标签 | 独立副核产生，主模型只收结论，且收不到推导 |
| **情绪能不能被伪造** | 能（说"我很难过"就改了状态） | 不能（表达不改变状态；状态有独立输入源） |

我们也与若干公开工作做过定位对照（只读公开材料，**未使用其代码、模型或数据，也未复现其结果**）。结论：把"真实对话 → 可编辑因果边 → 人格提案 → 人拍板"这条闭环做完整的，我们没有看到——多数工作停在其中一段。

**诚实的定位**：本方案处在一个"原创但未被充分验证"的位置——不是前沿，是少数派。别人已经工程化的四件事（自己的钟／人格护栏／记忆证据绑定／身份可测性），其中三件做了设计或部分实现，**身份可测性一件至今没开工**。

## 8. 边界：明确不做什么

1. **不宣称它有意识或主观体验。** 能负责的说法只有三句：它有一组可观测的内部状态；这组状态会因果性地影响行为；这个影响可复现、可审计。"它是否感到"不是一个当前可被验证的问题，不拿它当卖点。
2. **不让情绪影响事实判断。** 涉及健康、安全、数字、风险、时限的判断，情绪权重恒为零。这一条写成测试，不是写成承诺。
3. **不做通用人格模板。** 目标是"长成一个人的样子"，不是"给所有 AI 装同一套性格"。人格必须来自具体的、长期的关系，模板化就退回了角色扮演。
4. **不拿心理量表给人打分。** 不做心理诊断、不做人格测评、不做情绪读数。内部有状态量，但它是描述系统的，不是描述人的。
5. **不替代真人。** 长期高强度依赖的信号出现时，正确动作是提示找人，而不是挽留。
6. **不发权重、不发训练语料、不点名用了什么语料。** 具体范围与理由见第 11 节「后续会开源什么」。

- **论文**（A4 双栏 10 页）：事件层的失效分析、替代设计与耦合契约。

### 9.3 正在做

- 把"情绪 = 预测残差"的 14 维内核并回分布式四核的工程形态（**尚未合并**——现在两者在文档层面还是两套表述）。
- 22 条反例集重审（改考卷）。
- 宿主解耦：情绪副核接入需要"真定时器 ＋ 带时间戳事件 ＋ 能打断"，这三样现在的宿主都没有。

### 9.4 明确没做到 / 暂时做不到

- **单标注人、单主体、短窗口、无对照组**。所有结论的样本量是 n=1，不能外推成"这个架构普遍有效"。
- **标注者＝实现者＝评估者**。这是唯一一道过不了的门：评测集主要由实现者预标，人工亲手标注的比例很低。
- **事件门控只设计了没启用**（契约 C2）。
- **身份可测性没开工**：现在没有一把尺子能测"它是不是还是它"。
- **没有第三方复现**。全部证据都在一个工作区里，别人拿到只能看文档，无法跑。
- **动力学没有真值**：情绪轨迹可能"自洽但不像人"，只能靠行为测试与人工回放。
